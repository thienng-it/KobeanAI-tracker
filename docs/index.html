🚀 Quickstart Guide

Get KobeanAI Tracker running locally on your machine in less than 2 minutes.

1. Clone Repository

Clone the tracker to your development machine.

git clone https://github.com/thienng-it/KobeanAI-tracker.git
cd KobeanAI-tracker

2. Install & Start

Install dependencies and launch the dev environment.

npm install
npm run dev

3. Open Dashboard

Open in browser to see your live telemetry.

http://localhost:5173
(Backend on :3000)

🐳 Run with Docker (Alternative)

Prefer running everything inside an isolated container with zero setup?

docker compose up -d

App ready at http://localhost:3000 with automated health checks.

🔑 API Tokens & Live Transcript Ingestion

KobeanAI Tracker does not send your private code to remote tracking clouds. It monitors local transcript files generated on your computer:

Google Antigravity / Gemini CLI

Transcripts are parsed from:

~/.gemini/antigravity-ide/brain/<session-id>/.system_generated/logs/transcript.jsonl

Claude Code & Desktop

Transcripts are parsed from:

~/.claude/transcripts/*.jsonl

Configuring Environment API Keys (Optional)

If you run autonomous scripts or subagents that make direct API calls, export your keys in your shell or root .env file:

export GEMINI_API_KEY="AIzaSy..."
export ANTHROPIC_API_KEY="sk-ant-..."
export OPENAI_API_KEY="sk-proj-..."

🐙 Multi-Repository Contributor Guide

How to track your AI coding contributions across 10+ GitHub repositories seamlessly in one single dashboard.

Strategy 1: Universal Background Daemon (Zero Setup)

Leave KobeanAI Tracker running in background (npm run dev or docker compose up -d). As you switch between repositories and use your AI assistant, transcripts are automatically aggregated in SQLite.

Strategy 2: Prompt Tagging Conventions

Prefix prompts with repository tags so you can filter stats on the Sessions page:

[repo:facebook/react][issue-1234] Refactor useState hook microtask queue

Strategy 3: One-Click Log Re-Sync

Whenever you want to pull historical sessions from disk, open the Sessions page and click "Sync Real Logs".

🛡️ Secret Leak Protection (.betterleak)

Prevent accidental leaks of API tokens (OpenAI, Gemini, Anthropic, AWS, GitHub PATs) in public pull requests.

Pre-Commit Git Hook

Add this script to .git/hooks/pre-commit in any repository you contribute to:

#!/bin/sh
echo "🔍 Running .betterleak secret scan..."
git diff --cached | grep -E "(AIzaSy[0-9A-Za-z_-]{33}|sk-ant-[a-zA-Z0-9_-]{20,}|sk-[a-zA-Z0-9]{32,})"
if [ $? -eq 0 ]; then
  echo "❌ Sensitive API key detected in staged files! Aborting commit."
  exit 1
fi
echo "✅ No sensitive secrets found."
