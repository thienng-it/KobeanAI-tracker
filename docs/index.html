🚀 Quickstart Guide

Get KobeanAI Tracker running locally on your machine in less than 2 minutes.

1

Clone the GitHub Repository

Download the codebase to your local environment.

git clone https://github.com/thienng-it/KobeanAI-tracker.git
cd KobeanAI-tracker
2

Install Dependencies & Launch Dev Server

Starts both the Vite frontend (:5173) and hardened Express backend (:3000) concurrently.

npm install
npm run dev
3

Open Local Dashboard

Visit http://localhost:5173 to see real-time sessions and telemetry figures.

💡
Docker Container Option: If you don't want to run Node.js locally, run docker compose up -d. It builds the production container with health probes ready on port 3000.

🛡️ Secret Leak Protection (.betterleak)

Accidentally committing AI API tokens to public GitHub repositories can cost thousands of dollars. KobeanAI Tracker provides proactive leak prevention:

1. Standard Pre-Commit Hook

Add this script to .git/hooks/pre-commit in any repo you contribute to:

#!/bin/sh
echo "🔍 Running KobeanAI .betterleak secret check..."
# Scans staged diff for Google, OpenAI, Anthropic, AWS, and GitHub keys
git diff --cached | grep -E "(AIzaSy[0-9A-Za-z_-]{33}|sk-ant-[a-zA-Z0-9_-]{20,}|sk-[a-zA-Z0-9]{32,}|ghp_[a-zA-Z0-9]{36})"
if [ $? -eq 0 ]; then
  echo "❌ CRITICAL: Sensitive API key detected in staged files! Aborting commit."
  exit 1
fi
echo "✅ No sensitive tokens detected in commit."

2. GitHub Actions CI Secret Audit

The included .github/workflows/ci.yml workflow automatically scans every Pull Request against .betterleak definitions to guarantee zero leaked credentials.

❓ Frequently Asked Questions & Troubleshooting

Quick answers to common questions and troubleshooting steps.

Is my source code or prompt data sent to external servers? ▼
No. KobeanAI Tracker operates with 100% local-first privacy. All transcript parsing, token calculations, and database records are stored in a local SQLite file on your computer. Zero telemetry leaves your machine.
Why does my dashboard show 0 sessions initially? ▼
Make sure you have interacted with your AI assistant (e.g. Google Antigravity or Claude Code) so that local transcript logs exist. Then go to the Sessions page and click "Sync Real Logs" to scan your drive.
Does KobeanAI Tracker slow down my computer or IDE? ▼
No. KobeanAI Tracker uses lightweight asynchronous file watchers (Chokidar) that react only to file modification events. CPU and memory overhead is typically below 0.1%.
Can I track custom local models (e.g., Ollama or vLLM)? ▼
Yes! You can add custom connectors in server/connectors/ and set the cost per million tokens to $0.00 for local models.
